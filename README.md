# cargo

Программа для оценки вписывания крупногабаритного груза в габарит приближения строений на кривом участке железнодорожного пути. Позволяет определить степень и зону негабаритности, допустимый режим движения и строит наглядную расчётную схему.

## Основные возможности

- Выбор груза из предустановленного перечня.
- Ввод параметров участка пути: радиус кривой, возвышение наружного рельса, расстояние до сооружения с внутренней и внешней стороны кривой.
- Автоматический расчёт степени негабаритности и допустимого режима движения поезда с грузом.
- Вычисление минимально допустимых расстояний между осью пути и сооружением для пяти стандартных режимов движения.
- Графическое отображение расчётной схемы, где:
    - чёрным показан контур груза,
    - синим — габарит приближения строений,
    - серым — зоны и степени негабаритности,
    - красным — зазоры между грузом и очертанием габарита,
    - зелёным — рассчитанные минимально допустимые расстояния,
    - толстой красной линией — заданные размеры сооружения.
